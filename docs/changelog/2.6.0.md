## What's new

- Export custom field walls configured with `#meta wall` when building an option. In-game display requires the separate [wallbind plugin](https://github.com/ChuniPingu/wallbind#install) for MATE 2.50 x86

## Changes

- Use Export Option for both single-song and multi-song exports; the separate Export Song page has been removed

## Fixes

- Preserve multiline chart comments, relative media paths, shared-head ExTAP effects, and trailing scroll events during conversion
- Continue exporting when optional chart metadata is invalid, and stop audio export when normalization fails
