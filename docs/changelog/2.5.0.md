## What's new

- Support official MGXC v4 and UGC v9 charts
- Choose MGXC or UGC when extracting songs and C2S charts
- Follow running tasks and CLI activity from the status bar

## Improvements

- Show available metadata and the chart version when a newer chart cannot be converted
- Keep supported charts visible when a batch scan skips unsupported chart versions
- Keep page inputs, running tasks, results, and diagnostics when switching pages
- Run independent queries and tasks concurrently
- Add illustrated help and clearer asset and conversion diagnostics

## Changes

- Use official MGXC and UGC version semantics; custom editor dialects are no longer supported

## Fixes

- Preserve overlapping SLIDE paths, AIR relationships, scroll timelines, and numeric precision during chart conversion
- Retain chart metadata and note edits through supported round trips
- Show the window after startup and remember the sidebar state
- Improve task completion feedback and status bar activity updates
